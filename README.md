# Machine Learning Models for Breast Cancer Detection

This repository contains machine learning models that predict whether a tumor is malignant or benign based on the Breast Cancer Wisconsin dataset.

## Models:
- **Model 1**: Logistic Regression (v1) - A linear model used for binary classification.
- **Model 2**: Decision Tree (v2) - A non-linear model that classifies tumors based on decision rules.

## Dataset:
- The dataset used is the **Breast Cancer Wisconsin dataset** (UCI Machine Learning Repository).
- Features include various measurements such as radius, texture, smoothness, and area of the tumor.

## Steps:
1. Data Preprocessing: Clean and normalize the data.
2. Model Training: Train models using Logistic Regression and Decision Tree classifiers.
3. Model Evaluation: Evaluate the models using accuracy, confusion matrix, and classification report.
